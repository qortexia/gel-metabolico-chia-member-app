# Gel Metabólico de Chía — App de Miembro (onboarding)

App post-compra: onboarding de 8 etapas + (en fases futuras) panel diario del protocolo de 21
días. Ver `docs/superpowers/plans/` para el plan de implementación y
`../app-membro-design.md` para el diseño completo.

## Desarrollo

```bash
npm install
npm run dev
```

Corre en `http://localhost:3100` (puerto distinto al de `quiz-app`, que usa el 3000).

## Pruebas

```bash
npm test
```
